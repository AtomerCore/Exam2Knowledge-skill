# Exam2Knowledge

Transform questions into **pattern-recognition**: see → recognize → trigger → answer.

**Input:** Questions, exams, materials | **Output:** [output-template.md](./assets/output-template.md)

## Core Workflow (6 Steps)

1. **Pattern Recognition** → Type + cognitive level ([blooms-taxonomy.md](./references/blooms-taxonomy.md)) + hidden intent
2. **Reverse-Engineer Knowledge** → Ranked: [***] Must-Master | [**] Frequent | [*] Optional
3. **Build Reflex Frameworks** → Universal templates (80%+ variations) + heuristics
4. **Error Pattern Library** → Catalog mistakes ([diagnostic-rubric.md](./references/diagnostic-rubric.md))
5. **Cross-Question Intelligence** → Frequency ranking + clusters + trends (batch mode)
6. **Action-Oriented Output** → Prioritized by exam importance

## Decision Rules

| Scenario | Action |
|----------|--------|
| Single question | Full analysis + solution template |
| Multiple questions | Add frequency ranking + trends |
| Time pressure (<2 weeks) | Focus on [***] only |
| Weak topic | Target specific error patterns |
