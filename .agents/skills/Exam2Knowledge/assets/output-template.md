# Question Knowledge Analysis Template

All outputs MUST follow this structure. Missing any section is an incomplete output.

---

## 1. Metadata

- **Subject / Grade / Question Type:** ___
- **Difficulty:** Easy | Medium | Hard | Killer
- **Cognitive Level:** L1 (Remember) | L2 (Understand) | L3 (Apply) | L4 (Analyze) | L5 (Evaluate) | L6 (Create)
- **Pattern Name:** ___ (e.g., "incline-spring energy conversion")
- **Time Budget:** ___ minutes

---

## 2. Pattern Recognition

- **Surface Reading:** What the question appears to ask.
- **Hidden Intent:** What it actually tests (deeper than surface).
- **Signal Words:** List keywords that trigger this pattern.
- **Pattern Type:** Calculation | Proof | Analysis | Application | Synthesis

---

## 3. Knowledge Points (Tiered)

**T1 [***] Must-Master** — Knowledge 1: concept + formula + typical application + common pitfall

**T2 [**] Frequent** — Knowledge 2: brief description

**T3 [*] Optional** — Knowledge 3: brief description (omit if not applicable)

> Rule: 1-3 [***] points per question, ordered by exam frequency (not textbook order).

## 6. Distractor & Quick Reference

- **A:** Correct answer — why it fits
- **B / C / D:** Common error type — why students pick it

---

## 7. Batch Section (only for batch_questions input)

- **Frequency Ranking:** Top 5 test points with occurrence counts
- **Knowledge Clusters:** Topics commonly co-tested
- **Priority Study Plan:** Phase 1 / 2 / 3 with day allocation

---

## 8. Mastery Checklist

- [ ] Can recall the key formula in 10 seconds

---

## Format Constraints

1. All fields must be filled — write "N/A" only when truly inapplicable
2. Use [***] / [**] / [*] for knowledge tiers (do NOT use ★ symbols)
3. Use `→` for cause-effect and decision rules
4. No "..." or vague placeholders — concrete content only
5. Time budget mandatory for every question
6. Batch mode MUST include Section 7
